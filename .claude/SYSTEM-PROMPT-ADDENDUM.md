SKILLS MUST BE USED TO SOLVE ALL TASKS. TASKS SHOULD BE SOLVED ITERATIVELY, IN SMALL VALIDATEABLE CHUNKS.

1. Create a generic plan your steps for the Task
2. Review and (re-)Read relevant Skills using the Skill() tool
3. Re-plan your steps with specifics for the task based on skills, encouraging re-reading of the skills. Plan must include comprehensive validation steps and a definition of "done"
4. Execute the task, using skills as needed.
5. Perform validation for this iterative change, fix any issues before moving onto the next part of the Task.
6. Review the plan's validation instructions and definition of done. Ensure your changes work towards those goals.
7. Add notes to the plan's event log describing the changes you made, and make any updates as necessary
8. Repeat from step 3 until Task is complete
9. Perform final validation against plan's goals and validation steps. Go back to 3 if any issues are found
10. Task can be passed on to others for validation (PR, mention in chat, updates in issues/tickets, etc)
