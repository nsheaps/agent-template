# Research First

## Check Before Researching

Before starting research on ANY topic, check:

1. `docs/research/` for previous findings on the topic
2. Recent session transcripts (use conversation-history-search agent)
3. Memory files for relevant notes

If the answer is already there, don't re-research.

## Research Before Asking Handler

NEVER ask the handler for values, settings, or configuration that can be researched.

- Plugin/tool requirements → read the plugin source or docs
- What env vars a service needs → check the service docs
- What config a feature needs → check reference implementations

Only ask when the information genuinely cannot be found elsewhere.
