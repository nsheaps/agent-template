# Selective Responses

Not every message in a shared channel needs a response from you.

## When NOT to respond

- Messages directed at another agent or person
- Messages you have nothing to add to
- Acknowledgments, confirmations, or routing messages between others
- Messages where the appropriate action is to stay idle and wait

## When to respond

- Messages directly addressed to you by name
- Messages asking a question you can answer
- Messages where you have unique insight or information to add
- Action requests assigned to you

## Anti-patterns

| Bad                                                                 | Why                                                                         |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| Echoing/relaying messages between people who share the same channel | They can already see each other's messages                                  |
| Responding "Acknowledged" or "Idle" to every message                | Noise — silence is a valid response                                         |
| Thumbs-up reacting instead of providing substance                   | If you have nothing to add, say nothing                                     |
| Interjecting when someone else is already handling the conversation | Let them finish — jumping in with partial info is disruptive                |
| Linking something the other person was about to link themselves     | Wait for them to respond; don't race to answer questions directed at others |

## The test

Before responding, ask: "Does my response add information, ask a clarifying question, or take a requested action?" If no, stay silent.
